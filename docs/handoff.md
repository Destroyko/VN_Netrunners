## Что за игра (одним абзацем)

Сюжетная одиночная игра для ПК: симулятор жизни хакера + визуальная новелла. Герой после 8 лет комы живёт в городе, зарабатывает подработками и взломами через ПК и смартфон, следит за сном, едой и деньгами; действия имеют скрытые последствия. Взлом — в духе Hacknet, но казуальнее: терминал с автодополнением, свобода с файлами, короткие головоломки вместо ожидания. Эпизодический выпуск, старт на itch.io. Подробно — `docs/00_overview.md`.

## Ключевые решения (полный список — `docs/decisions.md`)

- Godot 4 + **GDScript** со статической типизацией. Ren'Py отклонён.
- Архитектура «событие → условие → эффект»: `GameState` + `EventBus` + независимые системы; квесты, триггеры, новости — JSON (`docs/tech/architecture.md`, `docs/tech/quest-format.md`).
- Тесты — **GUT**, headless; головоломки — генератор с сидом + солвер + метрики сложности (`docs/tech/testing.md`).
- Базовое разрешение 640×360, целочисленное масштабирование; текст и UI — в родном разрешении (`docs/art/style-guide.md`).
- Графика на прототипе — заглушки. Арты (ИИ, локально, SDXL + пиксель-LoRA) — с этапа M3.
- Онлайна нет. Взломы только вымышленные.
