# Раскладка рабочего стола

Рабочий стол ПК — главный экран игры: через него идёт почти всё, кроме сцен новеллы.
Задача наброска — не переделывать интерфейс потом. Приложения — из [devices.md](../gameplay/devices.md).

## Разрешение и текст

**Решено 13.11.2026** (подробно — [resolution.md](resolution.md)): интерфейс живёт в пикселях
экрана. Больше разрешение — больше места, а не крупнее кнопки. Минимум 1280×720,
1024×768 тесно но работает; масштаб интерфейса — настройка. Раздел ниже объясняет, почему.

Из [style-guide.md](../art/style-guide.md): арт — 640×360 с целочисленным масштабированием,
**текст и элементы интерфейса рисуются в родном разрешении экрана**.

Практически это значит: обои и иконки — пиксельные ассеты 640×360, а окна, рамки, кнопки и
текст живут в слое интерфейса поверх и остаются чёткими на любом экране. Терминала в 640×360
хватило бы на ~40 символов в строку — для игры с большим количеством текста этого мало.

## Общая раскладка

```
┌──────────────────────────────────────────────────────────────┐
│ ▣ Терминал  ▣ Почта  ▣ Магазин     ← иконки приложений       │
│ ▣ Банк      ▣ Новости ▣ Мессенджер    (сетка слева сверху)   │
│ ▣ Работа    ▣ Сайт группы                                    │
│                                                              │
│         ┌─ Терминал ────────────────────── ─ □ ✕ ┐           │
│         │                                        │           │
│         │   окна приложений: тащатся за заголовок│           │
│         │   активное — поверх остальных          │           │
│         │                                        │           │
│         └────────────────────────────────────────┘           │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ ☰  День 3, 14:30 │ 1 240 ₽ │ ███░░ риск │ [Терминал][Почта] │
└──────────────────────────────────────────────────────────────┘
   меню    время      деньги    заметность    открытые окна
```

### Панель задач (внизу, всегда видна)

| Элемент | Что показывает |
| --- | --- |
| ☰ Меню | Настройки, сохранение, выход, сложность (только просмотр) |
| Время | `День 3, 14:30` — из `Clock.format_time()` |
| Деньги | Текущий баланс; подсвечивается при изменении |
| Риск раскрытия | Полоска из **10 делений**, без цифр. Пороговые этапы — каждые два деления (5 этапов), различаются цветом |
| Кнопки окон | Переключение между открытыми окнами, свёрнутые тоже здесь |

Почему 10 делений, а не 5: игрок должен различать масштаб ошибки. Провал головоломки
сдвигает полоску почти незаметно, доведённый трейс — сразу на два деления. При пяти
делениях обе ошибки выглядели бы одинаково. Этапы и последствия — в
[heat.md](../gameplay/heat.md).

Сытость и энергия — **не** на панели задач: это состояние тела, а не компьютера.
Решено: отдельный **виджет на рабочем столе**, который можно закрыть. Диегетично (как виджет
здоровья на настоящем рабочем столе) и не перегружает панель. Рисуем в M2, когда появятся
сами потребности.

### Иконки приложений

Сетка слева сверху, запуск двойным кликом. Недоступные приложения видны, но серые
(«Сайт группы» до вступления) — игрок понимает, что мир больше, чем ему пока открыто.

## Окна

| Свойство | Решение |
| --- | --- |
| Заголовок | Название приложения + кнопки: свернуть, развернуть, закрыть |
| Перетаскивание | За заголовок, окно не уходит за границы экрана целиком |
| Размер | Тянется за правый нижний угол; у каждого окна свой минимум |
| Фокус | Клик поднимает окно наверх; активное отличается цветом рамки |
| Память | Положение и размер окна запоминаются между открытиями (в пределах сессии) |
| Независимость | Закрытие окна ничего не ломает в логике (`architecture.md`): окно только показывает состояние |

## Окно терминала (главное в M1)

```
┌─ Терминал ───────────────────────────────────── ─ □ ✕ ┐
│ Corvid Linux 5.4 LTS (tty1)                           │
│ ядро 5.4.0-148-generic x86_64                         │
│                                                       │
│ home:/home$ connect 10.0.0.7                          │
│ соединение с 10.0.0.7 установлено                     │
│ вход отклонён                                         │
│ 10.0.0.7> probe                                       │
│ ...                                                   │
│ 10.0.0.7> _                                           │
└───────────────────────────────────────────────────────┘
```

- **Один экран, как у настоящей консоли** (решено 15.11.2026, по гейту M1): сверху заставка ОС
  (`data/terminal.json`, по `pc.os`), дальше вывод, строка ввода идёт сразу за последней строкой.
  У строки ввода нет рамки, меню по правой кнопке и вставки эмодзи. Клик в любом месте экрана
  ставит курсор в строку ввода.
- **Боковых панелей файлов и программ больше нет**: дерево и список выглядели как форма, а не
  как консоль. «Клик как альтернатива набору» (`hacking-loop.md`) переедет в окно «Файлы» и
  удобства хакерской ОС — см. `open-questions.md`.
- **Карта сети** — отдельное окно рядом с терминалом: квадратик = узел, подсветка = где
  игрок сейчас, линии = известные связи. После `scan` появляются новые квадратики.
  Показывает только то, что игрок уже узнал (`../gameplay/network.md`).
  В M1 — простые квадраты и линии, без красоты.
- **Справа** — вывод (прокрутка, моноширинный шрифт) и строка ввода.
- **Индикатор трейса** — в заголовке окна терминала: полоска остатка, пока игрок на
  защищённом узле. Плюс предупреждения текстом в выводе на половине и на последней четверти.
  Пока работает программа, полоска и часы заметно ускоряются — по ним видно, что время
  сейчас идёт быстрее (`../gameplay/time.md`).
  Цифры минут не показываем: полоска читается быстрее, а точный счёт превратил бы взлом
  в арифметику. Трейс тратится действиями, а не реальным временем (`../gameplay/hacking.md`).
- Головоломка открывается **модально поверх окна терминала**, не отдельным экраном:
  видно, что идёт трейс и что происходит вокруг.
- Панели можно свернуть — для тех, кому милее чистый терминал.

## Экраны вокруг рабочего стола

Решено 13.11.2026: до рабочего стола игра должна открываться нормальным меню, а не сразу
сценой. Это и порядок, и единственный честный способ задать сложность — она фиксируется
при старте игры.

| Экран | Что на нём | Когда |
| --- | --- | --- |
| Главное меню | Новая игра, Продолжить, Настройки, Об игре, Выход | **сделано** |
| Новая игра | Выбор сложности (4 уровня, `difficulty.md`) с пояснением каждого | **сделано** |
| Настройки | Громкость, окно/полный экран. Хранятся в `user://settings.cfg` | **сделано** |
| Об игре | Версия, движок; лицензии ассетов — к релизу (`../art/audio.md`) | **сделано** |
| Комната | Фон, клик по монитору и системному блоку, инвентарь с флешкой | **заглушка сделана** (`src/ui/room.tscn`, шаг 6), арты — M3 |

- «Продолжить» в M0.5 — неактивная кнопка: сохранения по роадмапу в M4.
- Сложность на экране новой игры решает проблему прототипа: раньше её нечем было задать,
  кроме отладочной консоли. Команда в консоли всё равно остаётся — для быстрых проверок.

### Что сделано в M1 (15.11.2026, шаг 7)

`src/ui/desktop/`: рабочий стол с иконками (недоступные серые), окна (заголовок, перетаскивание,
растягивание за угол, свернуть/развернуть/закрыть, фокус, запоминание положения в сессии, одно
окно на приложение), панель задач (меню, время, деньги, полоска заметности на 10 делений, кнопки
окон), окно терминала (один экран с заставкой ОС, вывод, строка ввода с историей и Tab, индикатор

Остальные приложения — пустые окна. Окно «Файлы» (менеджер) пока заглушка. Виден ли интерфейс глазами и удобно ли им пользоваться — **ещё не проверено
человеком**, только тестами (`open-questions.md`).

## Что ещё уточнить на M1

- Минимальные размеры окон и поведение на 1280×720 (×2) — самом тесном поддерживаемом экране.
- ~~Нужна ли панель задач во время головоломки~~ — **решено 15.11.2026:** головоломка — обычное окно (`app_id = puzzle`, без иконки): его можно свернуть, закрытие = «выйти» (засчитывается собранное), `dc` закрывает его сам. Игровое время при этом стоит. Было модальным, но игрок не мог закрыть его.

## Концепция: взлом с виджетами рядом с консолью (черновик разработчика, 15.11.2026)

Не окончательно — направление, к которому идём. Образец — Hacknet (карта и «Open Ports» рядом с
терминалом) и удалённые клиенты вроде Radmin.

1. **`connect` открывает рядом с консолью виджет карты сети** (слева или справа), приближенный к
   узлу, к которому подключились.
2. **`scan` / `deepscan`** — результат и в консоли, и на карте в виджете (новые узлы появляются).
3. **`probe`** — кроме текста в консоли открывается виджет с **блоками защиты** узла: цвет или
   значок «вскрыт / закрыт». Пока виджет открыт, вскрытие сервиса сразу меняет его блок.
4. **Доступ к файловой системе** (даже неполный) открывает графическое окно файлов — аналог
   проводника — параллельно с консолью. `connect` по сути открывает «тонкий клиент» к узлу.
5. **Свобода выбора:** с файлами можно работать и командами, и в проводнике — хотя бы часть:
   копировать через меню по правой кнопке, перетаскивать мышью. Игрок сам решает, чем пользоваться.

Связано: «клик как альтернатива набору» (`gameplay/hacking-loop.md`), окно «Файлы» (сейчас
заглушка), панель защиты (`ideas/inbox.md`). Когда делать — `open-questions.md`.
