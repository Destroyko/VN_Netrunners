# Раскладка рабочего стола

Рабочий стол ПК — главный экран игры: через него идёт почти всё, кроме сцен новеллы.
Задача наброска — не переделывать интерфейс потом. Приложения — из [devices.md](../gameplay/devices.md).

## Разрешение и текст

**Решено 13.11.2026** (подробно — [resolution.md](resolution.md)): интерфейс живёт в пикселях
экрана. Больше разрешение — больше места, а не крупнее кнопки. Минимум 1280×720,
1024×768 тесно но работает; масштаб интерфейса — настройка. Раздел ниже объясняет, почему.

Из [style-guide.md](../art/style-guide.md): графика — рендеры и картинки-ассеты,
**текст и элементы интерфейса рисуются движком в родном разрешении экрана**.

Практически это значит: обои — рендер из Blender, иконки — отдельные картинки, а окна, рамки,
кнопки и текст живут в слое интерфейса поверх и остаются чёткими на любом экране. Терминала
в 640×360 хватило бы на ~40 символов в строку — для игры с большим количеством текста этого мало.

## Общая раскладка

```
┌──────────────────────────────────────────────────────────────┐
│ ▣ Терминал  ▣ Почта  ▣ Магазин     ← иконки приложений       │
│ ▣ Банк      ▣ Новости ▣ Мессенджер    (сетка слева сверху)   │
│ ▣ Работа    ▣ Сайт группы                                    │
│                                                              │
│         ┌─ Терминал ────────────────────── ─ □ ✕ ┐           │
│         │                                        │           │
│         │   окна приложений: тащатся за заголовок│           │
│         │   активное — поверх остальных          │           │
│         │                                        │           │
│         └────────────────────────────────────────┘           │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ ☰  День 3, 14:30 │ 1 240 ₽ │ ███░░ риск │ [Терминал][Почта] │
└──────────────────────────────────────────────────────────────┘
   меню    время      деньги    заметность    открытые окна
```

### Панель задач (внизу, всегда видна)

| Элемент | Что показывает |
| --- | --- |
| ☰ Меню | Настройки, сохранение, выход, сложность (только просмотр) |
| Время | `День 3, 14:30` — из `Clock.format_time()` |
| Деньги | Текущий баланс; подсвечивается при изменении |
| Риск раскрытия | Полоска из **10 делений**, без цифр. Пороговые этапы — каждые два деления (5 этапов), различаются цветом |
| Кнопки окон | Переключение между открытыми окнами, свёрнутые тоже здесь |

Почему 10 делений, а не 5: игрок должен различать масштаб ошибки. Провал головоломки
сдвигает полоску почти незаметно, доведённый трейс — сразу на два деления. При пяти
делениях обе ошибки выглядели бы одинаково. Этапы и последствия — в
[heat.md](../gameplay/heat.md).

Сытость и энергия — **не** на панели задач: это состояние тела, а не компьютера.
Решено: отдельный **виджет на рабочем столе**, который можно закрыть. Диегетично (как виджет
здоровья на настоящем рабочем столе) и не перегружает панель. Сделано 16.11.2026: виджет
«Самочувствие» в правом верхнем углу (`NeedsWidget`; **убран 17.11.2026 — самочувствие в строке
свёрнутого телефона, `gameplay/devices.md`**), мысли героя — внизу по центру поверх окон
(`HeroThoughts`); подробно — `gameplay/needs.md`. **Виджет — заглушка:** где показывать
самочувствие (и деньги вместе с ним) — частью интерфейса или виджетом в смартфоне, — открытый
вопрос (`open-questions.md`).

### «Пуск» и выход из-за ПК (плейтест M2, 17.11.2026)

- **«Пуск» (☰)** — только то, что относится к компьютеру: «Терминал», «Перезагрузить»,
  «Выключить». Программы и блокнот — в M3. «Сохранить игру» и выход в главное меню — не здесь.
- **Отойти от ПК** — заметная кнопка «Отойти от ПК (Esc)» справа на панели задач, далеко от
  «Выключить», и клавиша **Esc** (если её не забрало открытое окно-диалог).
- **В комнате Esc** (или кнопка «Меню») открывает **меню игры**: «Продолжить», «Сохранить игру»,
  «В главное меню». Пока меню открыто, время стоит. Лесенка: Esc за ПК — отойти, Esc в комнате —
  меню игры. Код — `src/ui/pause_menu.gd`.

### Отойти от ПК и вернуться

Решено 17.11.2026 (разработчик). Ушёл от компьютера (меню «В комнату», кнопка аварийной консоли,
вырубание) — рабочий стол **прячется, а не уничтожается**: окна, программы, открытые файлы и
набранная, но не отправленная команда остаются. Сел к монитору — тот же стол.

- Снаружи не должно быть заметно, что ПК не выключен: пока стол спрятан, **звук ПК заглушён**.
  Правило для всех будущих звуков стола (оповещения, программы, музыка) — играть их в шину `PC`
  (`Desktop.PC_BUS`).
- Спрятанный стол не принимает ввод (консоль F1 молчит) и не отвечает на вырубание — его
  показывает комната. Время и логика идут: трейс на узле, фоновые задачи, таймеры головоломок
  (не успел — провал, как при выходе).
- Выход в главное меню и новая игра стол уничтожают. **Выключение ПК** — тоже (это не «отошёл»):
  окна закрыты, подбор прерван, связь с узлом оборвана (`gameplay/hacking.md`, «Питание ПК»).
- Код: `Desktop.leave_to`, `hide_pc` / `show_pc`, `Desktop.enter_pc` (комната), `discard_kept`.

### Иконки приложений

Пустые заглушки — «Работа» (поиск работы и подработки, `gameplay/devices.md`) и «Мессенджер» —
серые до M3 (поле `stub` в списке приложений стола): кликать в пустое окно незачем (плейтест M2).

Сетка слева сверху, запуск двойным кликом. Недоступные приложения видны, но серые
(«Сайт группы» до вступления) — игрок понимает, что мир больше, чем ему пока открыто.

| Свойство | Решение |
| --- | --- |
| Заголовок | Название приложения + кнопки: свернуть, развернуть, закрыть |
| Перетаскивание | За заголовок, окно не уходит за границы экрана целиком |

## Окно терминала (главное в M1)

```
┌─ Терминал ───────────────────────────────────── ─ □ ✕ ┐
│ Corvid Linux 5.4 LTS (tty1)                           │
│ ядро 5.4.0-148-generic x86_64                         │
│                                                       │
│ home:/home$ connect 10.0.0.7                          │
│ соединение с 10.0.0.7 установлено                     │
│ вход отклонён                                         │
│ 10.0.0.7> probe                                       │
│ ...                                                   │
│ 10.0.0.7> _                                           │
└───────────────────────────────────────────────────────┘
```

- **Один экран, как у настоящей консоли** (решено 15.11.2026, по гейту M1): сверху заставка ОС
  (`data/terminal.json`, по `pc.os`), дальше вывод, строка ввода идёт сразу за последней строкой.
  У строки ввода нет рамки, меню по правой кнопке и вставки эмодзи. Клик в любом месте экрана
  ставит курсор в строку ввода; после Enter курсор остаётся в строке, а активное окно терминала
  сразу отдаёт ей фокус (16.11.2026).
- **Боковых панелей файлов и программ больше нет**: дерево и список выглядели как форма, а не
  как консоль. «Клик как альтернатива набору» (`hacking-loop.md`) переедет в окно «Файлы» и
  удобства хакерской ОС — см. `open-questions.md`.
- **Карта сети** — отдельное окно рядом с терминалом: квадратик = узел, подсветка = где
  игрок сейчас, линии = известные связи. После `scan` появляются новые квадратики.
  Показывает только то, что игрок уже узнал (`../gameplay/network.md`).
  В M1 — простые квадраты и линии, без красоты.
- **Справа** — вывод (прокрутка, моноширинный шрифт) и строка ввода.
- **Индикатор трейса** — в заголовке окна терминала: полоска остатка, пока игрок на
  защищённом узле. Плюс предупреждения текстом в выводе на половине и на последней четверти.
  Пока работает программа, полоска и часы заметно ускоряются — по ним видно, что время
  сейчас идёт быстрее (`../gameplay/time.md`).
  Цифры минут не показываем: полоска читается быстрее, а точный счёт превратил бы взлом
  в арифметику. Трейс тратится действиями, а не реальным временем (`../gameplay/hacking.md`).
- Головоломка открывается **модально поверх окна терминала**, не отдельным экраном:
  видно, что идёт трейс и что происходит вокруг.
- Панели можно свернуть — для тех, кому милее чистый терминал.

## Экраны вокруг рабочего стола

Решено 13.11.2026: до рабочего стола игра должна открываться нормальным меню, а не сразу
сценой. Это и порядок, и единственный честный способ задать сложность — она фиксируется
при старте игры.

| Экран | Что на нём | Когда |
| --- | --- | --- |
| Главное меню | Новая игра, Продолжить, Настройки, Об игре, Выход | **сделано** |
| Новая игра | Выбор сложности (4 уровня, `difficulty.md`) с пояснением каждого | **сделано** |
| Настройки | Громкость, окно/полный экран. Хранятся в `user://settings.cfg` | **сделано** |
| Об игре | Версия, движок; лицензии ассетов — к релизу (`../art/audio.md`) | **сделано** |
| Комната | Фон, клик по монитору и системному блоку, инвентарь с флешкой | **сцена на данных** (M3, шаг 3: `gameplay/locations.md`), арты — шаг 10 M3 |

- «Продолжить» в M0.5 — неактивная кнопка: сохранения по роадмапу в M4.
- Сложность на экране новой игры решает проблему прототипа: раньше её нечем было задать,
  кроме отладочной консоли. Команда в консоли всё равно остаётся — для быстрых проверок.

## Концепция: взлом с виджетами рядом с консолью (черновик разработчика, 15.11.2026)

Не окончательно — направление, к которому идём. Образец — Hacknet (карта и «Open Ports» рядом с
терминалом) и удалённые клиенты вроде Radmin.

1. **`connect` открывает рядом с консолью виджет карты сети** (слева или справа), приближенный к
   узлу, к которому подключились.
2. **`scan` / `deepscan`** — результат и в консоли, и на карте в виджете (новые узлы появляются).
3. **`probe`** — кроме текста в консоли открывается виджет с **блоками защиты** узла: цвет или
   значок «вскрыт / закрыт». Пока виджет открыт, вскрытие сервиса сразу меняет его блок.
4. **Доступ к файловой системе** (даже неполный) открывает графическое окно файлов — аналог
   проводника — параллельно с консолью. `connect` по сути открывает «тонкий клиент» к узлу.
5. **Свобода выбора:** с файлами можно работать и командами, и в проводнике — хотя бы часть:
   копировать через меню по правой кнопке, перетаскивать мышью. Игрок сам решает, чем пользоваться.

Связано: «клик как альтернатива набору» (`gameplay/hacking-loop.md`), окно «Файлы» (сейчас
заглушка), панель защиты (`ideas/inbox.md`). Когда делать — `open-questions.md`.

## Удалённый сеанс (сделано 15.11.2026)

Первый кусок концепции выше. После `connect` к **ПК** рядом с консолью открывается окно
«Удалённый сеанс — адрес»: трансляция рабочего стола цели, как в Radmin или при входе в Windows.

- **Экран блокировки** (как Win+L): обои цели, имя пользователя, поле пароля. Появляется, когда
  сервер спрашивает пароль (`gameplay/hacking.md`, «Пароль после перехвата»). Ввести можно здесь
  или в консоли — путь один, и вход виден в обоих местах.
- **Стол цели**: обои, иконки из данных узла (пока только «Проводник»), панель внизу
  `пользователь@адрес` и часы. Консоли на столе цели нет: у цели обычная ОС.
- **Проводник** открывается окном внутри трансляции (окна не уходят за край удалённого экрана).
  Пока только просмотр: папки — двойной клик, «..» — наверх; свой путь, консоль он не двигает.
- **Роутер и сервер** графического сеанса не имеют — только консоль.
- Заказ дал логин — пароль не спрашивают, трансляция сразу показывает стол.
- `dc`, обрыв или трейс — трансляция закрывается. И наоборот: **закрыть окно трансляции = `dc`** (16.11.2026).
- Правил в окне нет: что разрешено (фаервол, права, трейс), решают системы — одинаково для мыши и
  для консоли. **Действие мышью — это команда той же консоли** (`cat`, `rm`, `mv`, `cp`): она видна
  в консоли, а последняя строка ответа — внизу проводника («недостаточно прав»). Вопрос «y/n»
  (системный файл) задаётся окном подтверждения.
- **Меню по правой кнопке, как в Windows:** Открыть (папку — войти, файл — «Блокнот» внутри
  трансляции), Копировать, Вырезать, Вставить, Переименовать, Удалить. Вставить в папке узла —
  перемещение вырезанного (`mv`); скопированное внутри узла не вставляется (так не умеет и консоль).
- **Буфер как в RDP:** скопировал файл в трансляции — правая кнопка по своему рабочему столу,
  «Вставить» — файл скачивается к себе (как `cp`). То же — перетащить файл из проводника на свой стол.
- Права как в Unix: гость только читает и скачивает; удалить, переименовать, переместить — после
  `rootstep`.

Стол цели — в данных узла, поле `desktop` (`tech/terminal-spec.md`, «Формат узла»).
Код: `src/ui/desktop/remote_session.gd`, `file_browser.gd`, `login_form.gd`.

### Две версии ОС (решено 15.11.2026)

- **Обычная ОС** — у целей: рабочий стол, темы (позже — обои), без хакерского софта и консоли.
  Её видно через удалённый сеанс.
- **Хакерская ОС** — у игрока: консоль, программы, виджеты, трейс и прочее.
- Исключение: **стартовая ОС игрока** обычная, но с консолью — единичный временный случай по сюжету
  (первые задания с прямым доступом), до перехода на хакерскую.
