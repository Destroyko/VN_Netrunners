## Шаг 2 — диалоги

- [ ] Консоль F1: `dialogue dlg_test` — внизу окно диалога, слева плашка вместо портрета
      (цвет персонажа, имя, эмоция), имя над текстом цветом.
- [ ] Текст набирается постепенно; **клик мышью** (по тексту, по портрету, где угодно на экране),
      пробел или Enter во время набора — вся строка сразу, следующий клик — следующая реплика.
- [ ] Слово «passhound» выделено цветом; навёл мышь — подсказка.
- [ ] Выборы — кнопками; «Не сейчас» снижает отношение соседки (`state` / переменная `rep.roommate`).
- [ ] Мысль героя — курсивом и серым, без плашки; авторский текст — без имени.
- [ ] Пока идёт диалог, часы стоят; закончился — пошли.
- [ ] `H` (не в поле ввода) — журнал реплик; выборы отмечены стрелкой.
- [ ] Настройки → «Скорость текста»: медленно / обычно / быстро / сразу — сказывается на окне.

## Шаг 3 — сцены и квартира

- [ ] «Новая игра» — сцена «Комната»: плашки окна, монитора, системного блока, кровати и двери;
      наверху название, часы, «Меню (Esc)».
- [ ] Наведение на плашку подсвечивает её; клик по окну — текст внизу.
- [ ] Системный блок и кровать открывают панель рядом с объектом; повторный клик, клик по фону
      или Esc её закрывают; следующий Esc — меню игры.
- [ ] Кровать: будильник, «Спать» — время прыгает, часы наверху обновились.
- [ ] Комната → прихожая → кухня → прихожая → комната; входная дверь и соседняя не пускают.
- [ ] Кухня: холодильник — еда из доставки, «Поесть»; съел всё — «Пусто.».
- [ ] Отошёл от ПК — снова комната; сохранился в прихожей и загрузился — прихожая.
