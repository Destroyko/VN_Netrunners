# Языки и переводы

Цель: все тексты для игрока — в одном месте, переводятся без декомпиляции проекта. Мододел
кладёт папку с переводом рядом с игрой — язык появляется в настройках (как `game/tl/<язык>/` у
Ren'Py).

## Как устроено

- **Ключ — исходный русский текст.** В коде строка для игрока пишется через
  `tr("файл не найден: %s")`; перевода нет — показывается русский (так делают Godot и Ren'Py,
  «old → new»). Тексты в коде остаются читаемыми, id придумывать не нужно.
- **Формат перевода — gettext `.po`**: стандартные инструменты (Poedit, сервисы перевода);
  Godot читает `.po` сам, в том числе с диска во время игры.
- **Папка переводов:** `translations/<язык>/` рядом с игрой и в папке пользователя; при старте
  игра подхватывает всё, что там лежит.
- **Сборщик шаблона** (`tools/`): все строки в один `game.pot` — из кода (`tr("…")`) и из данных
  (реплики диалогов, письма, сообщения, квесты, новости, предметы, локации — по известным полям
  JSON). Перевод — копия шаблона с заполненными строками; новая версия игры — шаблон обновляется,
  новые и изменённые строки видны.
- **Числа и падежи** («найдено узлов: 3», «3 дня») — формы множественного числа `.po`.
- **Шрифт:** IBM Plex держит латиницу и кириллицу; для других письменностей — запасной шрифт
  (забота переводчика).

## Язык игры

- **Первый запуск** (после установки): сразу выбор языка. Предложен язык системы: русский, если
  система русская, иначе английский.
- **Дальше** — смена в настройках игры.

## Правило

Любой текст для игрока — через `tr()` в коде или в данных (`data/`). Строка для игрока прямо в
коде без `tr()` — ошибка (правило — в `CLAUDE.md`, когда каркас будет сделан).
