# Визуальный стиль

Канон стиля игры. Фоны собираются и рендерятся в Blender (`blender-scenes.md`),
персонажи рисуются ИИ (`ai-pipeline.md`). Этот файл держит их в одной манере.

## Откуда берётся графика

**Вся графика игры — это рендеры из Blender либо отдельные картинки-ассеты.** Третьего нет.

| Что | Откуда | Где описано |
| --- | --- | --- |
| Фоны локаций, меню, карта города, кадры «комната до/после» | **рендер из Blender**, сцены собираются из CC0-ассетов и палитры игры | `blender-scenes.md` |
| Слои фона: маска интерактивности, экран монитора, переходы камеры | **рендер из Blender** (отдельные проходы той же сцены) | `blender-scenes.md` |
| Портреты персонажей | отдельные картинки, рисует ИИ | `ai-pipeline.md` |
| Иконки приложений, аватарки, значки | отдельные картинки | — |
| Окна, рамки, кнопки, текст | **не картинки**: рисуются движком, в родном разрешении экрана | `../tech/resolution.md` |

Новый арт в игру приходит одним из двух путей: отрендерить сцену в Blender или положить
готовую картинку-ассет. Если нужна графика, которая не подходит ни под один путь, спросить.

## Направление

- **Мягкий полуплоский 3D (2.5D).** Сцена трёхмерная, но выглядит рисованной:
  ступенчатый свет вместо плавного, мягкие пастельные цвета, почти без текстур
  и совсем без бликов.
- **Персонажи — смесь cartoon и anime:** плоская заливка, читаемые формы, **без
  типичных аниме-штампов** — без огромных глаз, нос есть. Пропорции ближе
  к человеческим, чем к аниме.
- **Референс по ощущению:** MiSide — мягкий свет, пастель, плоские поверхности.
  Берём **признаки** (разобраны в `blender-scenes.md`), а не чужие ассеты:
  приёмы cel-шейдинга общие для десятков игр.
- **Мир:** наше время / ближайшее будущее, корпорации, хакеры. Приземлённо
  и правдоподобно: обычные квартиры, улицы, офисы, экраны. Неон — акцентом.
- **Подача как в визуальных новеллах:** статичный фон + портрет персонажа поверх.
  Плюс интерфейсы ПК и смартфона.

## Технические параметры

Разрешение и масштабирование настроены в `project.godot`. Интерфейс живёт в пикселях экрана
(`../tech/resolution.md`), фон растягивается под окно с обычной фильтрацией.

| Параметр | Значение |
| --- | --- |
| Разрешение финального рендера фона | **1920×1080** (предложено, ждёт подтверждения: `open-questions.md`). На 2К и 4К масштабируется фильтром, дробный масштаб не страшен |
| Портрет персонажа | пропорция 1:2, по пояс. Размер не закреплён, решается вместе с манерой персонажей |
| Цвета фона | **палитра игры «цвет × материал»** (`blender-scenes.md`): 59 цветов, 9 типов материалов. Вид в рендере — `Standard`, не `AgX` |
| Цвета портрета | в тех же тонах, что палитра фона; число цветов не ограничено |
| Контур | у персонажей — тёмный цветной, мягкий; у фонов — без контура |
| Свет | Ступенчатые тени (cel-шейдинг), источники света видны в сцене (монитор, лампа, вывеска, окно) |
| Масштабирование | обычное, с линейным фильтром (`project.godot`) |

**Текст — не картинка.** В игре много текста (терминал, почта, диалоги): он и интерфейс
рисуются в родном разрешении экрана, поверх рендера, и остаются чёткими на любом мониторе.

## Единообразие персонажей

- У каждого персонажа есть **фиксированное описание внешности** (одна строка на английском) в его карточке в `../characters/`. Оно вставляется в каждый промпт без изменений.
- Сначала генерируется **лист персонажа** (анфас, эмоции), дальше все портреты — от него.
- Набор эмоций для портретов (минимум): нейтрально, улыбка, удивление, злость, грусть, смущение, задумчивость.
- **Порядок работы с персонажем** (решено 16.11.2026, по этапам — раньше не перескакивать):
  1. Найти лицо: много генераций портрета, отобрать одно удачное, довести руками — это эталон.
  2. Размножить эталон на 6–8 эмоций (редактирование по референсу плюс ручная правка).
     Меняется только лицо, одежда и плечи копируются.
  3. Эти кадры и есть датасет — обучить на нём LoRA персонажа.
  4. Проверить: рисует ли она **того же человека** в новой эмоции.
  5. Только после этого — позы, другая одежда, кадры крупнее.
- **Ручная доводка в редакторе — часть конвейера, а не признак неудачи.** Плоская заливка
  и чистые контуры правятся быстрее, чем фотореалистичная иллюстрация.
- Если инструмент позволяет: сохраняем seed / референс-картинку персонажа и используем повторно.

## Шаблон промпта для портрета (на английском)

```
flat cartoon-anime character portrait, waist up, front view, soft cel shading,
muted pastel colors, clean thin dark colored outline, normal human proportions,
small eyes, visible nose, plain background,
[ОПИСАНИЕ ПЕРСОНАЖА: внешность, одежда],
[ЭМОЦИЯ]
```

Это стартовая заготовка: промпты портретов ещё не обкатаны (внешность персонажей не утверждена).
Описание способа и рабочие настройки — `ai-pipeline.md`, разделы 9 и 10.

- **Негатив не работает** на выбранных моделях (Z-Image и дистиллированная klein идут
  с CFG 1). Всё, чего быть не должно, формулируется в позитивном промпте утвердительно.

## Именование файлов

`bg_<локация>_<время>.png` (bg_apartment_night.png), `chr_<персонаж>_<эмоция>.png` (chr_roommate_smile.png), `ui_<элемент>.png`.

## Список артов для MVP (черновик)

- Фоны (рендеры): квартира ГГ (день/ночь, пустая и обжитая), коридор, кухня, улица у дома, 2–3 локации района, больница/клиника.
- Портреты: соседка (полный набор эмоций), мать, 1–2 второстепенных.
- UI: рабочий стол старой ОС, рабочий стол новой ОС, смартфон, иконки приложений.
