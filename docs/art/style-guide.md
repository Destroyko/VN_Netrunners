# Визуальный стиль и гайд для ИИ-генерации

Вся графика генерируется ИИ. Этот файл — контекст для каждой генерации, чтобы арты выглядели как одна игра, а не как набор случайных картинок.

## Направление

- **2D пиксель-арт с аниме-пропорциями персонажей.** Не 8-бит и не ретро: детальный современный пиксель-арт, пиксели чуть крупнее среднего.
- **Референс по ощущению:** [Probably Stolen](https://store.steampowered.com/app/4349200/) — современный пиксель-арт с киберпанк-атмосферой. Берём плотность пикселей и настроение, не копируем стиль один в один. В промптах название игры **не используем** — описываем признаки стиля словами (ниже).
- **Мир:** наше время / ближайшее будущее, корпорации, хакеры. Приземлённо и правдоподобно: обычные квартиры, улицы, офисы, экраны. Неон — акцентом, а не везде.
- **Подача как в визуальных новеллах:** статичный фон + спрайты персонажей поверх (не во всех сценах). Плюс интерфейсы ПК и смартфона.

## Технические параметры

Разрешение и масштабирование настроены в `project.godot` на M0. Размеры спрайтов и палитра —
пока предложение, проверяем на первых артах (M3).

| Параметр | Значение |
| --- | --- |
| Базовое разрешение фона | 640×360, масштаб ×3 до 1920×1080 (если пиксели нужны крупнее — 480×270, ×4) |
| Спрайт персонажа (в полный рост / по пояс) | ~200–260 px по высоте в базовом разрешении |
| Масштабирование | Только целым множителем, фильтр nearest neighbor (в Godot: Texture Filter = Nearest) |
| Палитра | Общая ограниченная палитра на игру (~32–48 цветов), отдельные акценты для корпорации и группы |
| Контур | Тёмный цветной контур у персонажей, у фонов — без контура или мягкий |
| Свет | Мягкие тени, 2–3 тона на материал, источники света видны в сцене (монитор, фонарь, вывеска) |

## Разрешение экрана и масштабирование

Базовое разрешение 640×360 делится нацело на все популярные 16:9 разрешения, поэтому пиксели масштабируются ровно, без «мыла» и неровных пикселей:

| Экран | Множитель |
| --- | --- |
| 1280×720 | ×2 |
| 1920×1080 | ×3 |
| 2560×1440 | ×4 |
| 3840×2160 | ×6 |

Для других пропорций (1920×1200, ультраширокие) — целый множитель + чёрные поля или расширенный фон.

**Текст — отдельно от пикселей.** В игре много текста (терминал, почта, диалоги). Если рисовать его в 640×360, он будет мелким и тесным. Поэтому: арт масштабируется пиксельно, а текст и интерфейс рисуются в родном разрешении экрана и остаются чёткими.

**Обновлено 13.11.2026:** модель масштабирования изменена — интерфейс живёт в пикселях экрана,
а пиксельный арт масштабируется целым множителем внутри своих сцен (`SubViewport` 640×360).
Подробно и с причинами — [resolution.md](../tech/resolution.md). Настройки ниже относятся
к арту, а не к интерфейсу.

Настройки Godot 4 для пиксельного арта:
- Viewport 640×360, `stretch mode = canvas_items`, `aspect = keep` (или `expand`), `scale_mode = integer`.
- Фильтр текстур по умолчанию — Nearest.
- Привязка 2D-объектов к пикселю (snap 2D transforms / vertices to pixel), чтобы спрайты не вставали «между пикселями».
- Шрифт: чёткий шрифт для текста; пиксельный шрифт — только для заголовков / акцентов, по желанию.

## Почему нужна постобработка

ИИ рисует «под пиксель-арт», но пиксели у него не лежат на ровной сетке, и цвета плывут. Поэтому каждый арт проходит конвейер:

1. Генерация в большом разрешении по шаблону промпта (ниже).
2. Уменьшение до базового разрешения фильтром nearest neighbor.
3. Приведение к палитре игры (квантизация цветов).
4. Ручная чистка: лишние пиксели, контур, артефакты, руки и лица.
5. Проверка на фоне игры рядом с уже готовыми артами.

## Единообразие персонажей

- У каждого персонажа есть **фиксированное описание внешности** (одна строка на английском) в его карточке в `../characters/`. Оно вставляется в каждый промпт без изменений.
- Сначала генерируется **лист персонажа** (анфас, эмоции), дальше все спрайты — от него.
- Набор эмоций для спрайтов (минимум): нейтрально, улыбка, удивление, злость, грусть, смущение, задумчивость.
- Если инструмент позволяет: сохраняем seed / референс-картинку персонажа и используем повторно.

## Шаблон промпта (на английском)

```
pixel art, detailed modern pixel art, slightly chunky pixels, anime-proportioned character,
near-future city, grounded realistic setting, muted colors with subtle neon accents,
soft lighting, clean dark colored outline, limited palette, game sprite / visual novel background,
[ОБЪЕКТ: описание персонажа или сцены],
[РАКУРС И КАДР: full body / waist up, front view, plain background для спрайтов],
[ВРЕМЯ СУТОК И СВЕТ: night, monitor glow / day, overcast]
```

Негатив (если инструмент поддерживает): `blurry, 3d render, photorealistic, smooth gradients, 8-bit, retro, chibi, text, watermark, extra fingers`.

Готовые промпты на конкретные кадры, разрешения под целое деление и формат, в котором
описывать новый кадр, — в [ai-pipeline.md](ai-pipeline.md), раздел «Промпты». Этот файл
остаётся каноном стиля: при расхождении правим здесь.

## Список артов для MVP (черновик)

- Фоны: квартира ГГ (день/ночь), комната ГГ, улица у дома, 2–3 локации района, больница/клиника.
- Спрайты: соседка (полный набор эмоций), мать, 1–2 второстепенных.
- UI: рабочий стол старой ОС, рабочий стол новой ОС, смартфон, иконки приложений.
