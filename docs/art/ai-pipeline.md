# Генерация графики локально

Идея: поднять локальную модель + скачать LoRA под пиксель-арт и генерировать через неё.

## Главное правило — лицензии

Игра может пойти в Steam, поэтому и базовая модель, и каждая LoRA должны разрешать коммерческое использование. Проверять лицензию на странице каждой модели и LoRA (Hugging Face / Civitai) и записывать в таблицу ниже.

- **FLUX.1 [dev] / FLUX.2 [dev]** — веса под некоммерческой лицензией; для коммерческой работы нужна платная лицензия у Black Forest Labs. Без неё — **не берём**.
- **SDXL** — лицензия CreativeML Open RAIL++-M, коммерческое использование разрешено (с ограничениями по поведению).
- **Animagine XL 4.0** (аниме-модель на SDXL) — та же лицензия, коммерческое использование разрешено.
- Остальное (Z-Image Turbo, FLUX.2 klein, Illustrious, отдельные LoRA) — проверить по карточке перед использованием.

## Варианты

| Вариант | Плюсы | Минусы | VRAM | Лицензия |
| --- | --- | --- | --- | --- |
| **SDXL + аниме-чекпоинт + пиксель-LoRA** (например, Pixel Art XL) | Самая большая экосистема LoRA и ControlNet, проще всего удерживать стиль | Хуже понимает сложные промпты | ~6–8 ГБ | SDXL — коммерческое ок; чекпоинт и LoRA — проверить |
| Z-Image Turbo + пиксель-LoRA | Очень быстро, есть отдельные LoRA под сцены, портреты, спрайты | Экосистема меньше | проверить | проверить |
| FLUX.2 klein + пиксель-LoRA для спрайтов | Новая, есть LoRA под спрайты с прозрачным фоном | Экосистема молодая | проверить | проверить |
| FLUX.1/2 [dev] | Лучшее следование промпту | Некоммерческая лицензия | 12+ ГБ | **не берём** без платной лицензии |

**Рекомендация для старта:** SDXL + аниме-чекпоинт с коммерческой лицензией + пиксель-LoRA, интерфейс ComfyUI. Причины: самый низкий порог по видеокарте, больше всего готовых LoRA, лицензия понятна.

**Позже:** если готовые LoRA не дают нужный стиль — обучить свою LoRA на 20–50 отобранных удачных артах игры. Это лучший способ получить единый стиль.

## Конвейер

1. ComfyUI: модель + LoRA + шаблон промпта из `style-guide.md`.
2. Генерация серии вариантов, выбор лучшего.
3. Постобработка: уменьшение nearest neighbor до 640×360 (фоны) / размера спрайта, приведение к палитре, ручная чистка.
4. Сохранение рядом с файлом настроек генерации (модель, LoRA, вес, seed, промпт) — чтобы повторить стиль.

## Раскрытие использования ИИ (при публикации)

- **Steam:** с января 2026 нужно раскрывать генеративный ИИ в контенте, который видят игроки (арт, звук, текст). Инструменты разработки (например, ИИ для кода) раскрывать не нужно.
- **itch.io:** есть обязательная отметка «AI Generated» / «No AI», по ней игроки фильтруют.
- Значит: отмечаем «AI Generated» для графики. Учитывать, что часть аудитории фильтрует такие игры.
