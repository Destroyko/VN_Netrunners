# Иконки интерфейса

Один набор форм для телефона и ПК: плоские значки простой геометрии, цвета из палитры комнат. Цвета значков зависят от темы ОС (`art/themes.md`: три схемы обычного ПК, хакерская, телефон); сейчас собрана тёмная заготовка (белое с оранжевым, под тёмный экран телефона). Для светлых схем ПК основной цвет значка делается тёмным (`art/themes.md`). Значок
хранится один раз, без плашки (ПК), а на телефоне собирается в плашку с закруглёнными углами.

## Где что лежит

| Что | Где |
| --- | --- |
| **Исходники значков** (правится руками) | `assets/_source/icons/glyphs/<имя>.svg` |
| Список иконок и цвет плашки каждой | `assets/_source/icons/icons.json` |
| Сборка | `python tools/icons/build_icons.py` |
| Готовые для игры | `assets/ui/icons/glyph/<имя>.svg` (ПК), `assets/ui/icons/tile/<имя>.svg` (телефон) |
| Лист для просмотра | `godot --path . res://tools/shot_icons.tscn` → `tools/out/icons.png` |

Цвета значка берутся из `data/ui_theme.json` (роли `text` и `accent`), цвет плашки — из палитры комнат по
имени. Сменили роль или палитру — запустили сборку, весь набор перекрасился.

## Правила стиля (чтобы новые значки не выбивались)

1. **Сетка 48×48**, значок внутри поля 6–42, отступ от края не меньше 6.
2. **Две краски:** `{fg}` (основная, светлая) и `{accent}` (одна деталь значка: стрелка, точка, ручка). Других цветов нет, в файле стоят метки `{fg}` и `{accent}`.
3. **Форма:** либо сплошная заливка, либо контур толщиной **3,5** со скруглёнными концами и углами (`stroke-linecap="round"`, `stroke-linejoin="round"`). Градиентов, теней и мелких деталей нет.
4. **Скругления:** у прямоугольников `rx` 3–5.
5. **Не вычурно:** один предмет, узнаваемый силуэт, 1–3 части.
6. **Плашка** (телефон): квадрат 96×96 с радиусом 22, значок 56×56 по центру. Цвет плашки — одно имя из палитры, приглушённый тон (`*_dark` или `*_mid`), чтобы ряд иконок не пестрил.

## Как добавить значок

1. Нарисовать `assets/_source/icons/glyphs/<имя>.svg` по правилам (любой редактор SVG или текстом, шаблоном служит любой из существующих).
2. Дописать строку в `assets/_source/icons/icons.json`: `title` и `tile` (имя цвета из `tools/blockout/palette.py`).
3. `python tools/icons/build_icons.py`, затем открыть Godot, чтобы он импортировал файлы, и посмотреть лист.
