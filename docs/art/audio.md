# Звук и музыка

- **Звуки:** бесплатные ассеты — клики мыши, клавиатура, гул ПК, уведомления, звуки ОС, улица.
- **Эмбиент и музыка:** бесплатные или по лицензии с указанием автора.

## Правила по лицензиям

- Берём только то, что разрешено в коммерческой игре (игра может пойти в Steam): CC0, CC-BY и аналоги.
- **Не берём** лицензии «только некоммерческое использование» (CC-BY-NC) — потом придётся всё менять.
- Каждый файл сразу вносим в таблицу ниже. Из неё собираются титры.

## Где искать (проверять лицензию у каждого файла)

- Kenney.nl — звуки интерфейса, CC0.
- Freesound.org — у каждого звука своя лицензия, смотреть отдельно.
- OpenGameArt.org — звуки и музыка, лицензия у каждого файла.
