# Обзор

## Питч

Сюжетная песочница о жизни хакера-одиночки. Игрок живёт в городе, зарабатывает взломами и подработками через домашний ПК и смартфон, следит за сном, едой и энергией. Каждое решение тянет за собой скрытые последствия: от обыска полиции до ограбления, если персонаж уснул на улице.

Формат: эпизодическая игра на itch.io, сюжет и механики добавляются обновлениями. Первая цель — красивый MVP на 1–3 часа геймплея.

## Главная фишка

Взлом как образ жизни: хакерский геймплей в духе Hacknet связан с бытом, деньгами и последствиями. Hacknet — только терминал, новеллы — только диалоги; здесь взлом кормит, утомляет и привлекает внимание.

- **Скрытые последствия.** Частые взломы → растёт заметность → обыск. Без сна на энергетиках → персонаж вырубается на 12 часов; на улице его могут ограбить.
- **Два устройства.** Домашний ПК — полный рабочий стол; смартфон на улице — урезанный набор для квестов, как в Watch Dogs.
- **Вымышленные программы вместо реальных техник.** Команды и .exe-утилиты, как в Hacknet, без работающих инструкций. Проще для обычного игрока.
- **Новелла поверх песочницы.** Сюжет через диалоги, сайд-квесты, репутация с персонажами, случайные ивенты.

Под силу одному: да — 2D-интерфейс, текст, статичные арты; нет боёвки, физики, онлайна. Главный риск — объём контента (тексты, квесты, арт) и баланс систем.

## Жанр и платформа

- Жанр: симулятор хакера + life-sim + визуальная новелла, одиночная.
- Платформа: ПК; сначала itch.io, потом возможно Steam.
- Аудитория: игроки новелл и «десктопных» игр, без технической подготовки.

## Движок

**Godot 4** (+ плагин Dialogic для диалогов — проверить в прототипе): ядро игры — интерактивный рабочий стол с окнами и терминалом.
Ren'Py отклонён: слишком ограничен и сильно заточен под визуальную новеллу, задуманные фичи там не реализовать. Unity избыточен.

## Визуал и звук

- Мягкий полуплоский 3D: **фоны — рендеры из Blender** (сцены из CC0-ассетов и палитры игры), **персонажи — 3D-модели, рендеры из Blender** (cartoon + anime, плоская заливка): в кадре на месте по расписанию и спрайтом по пояс в диалоге. Подача как в визуальных новеллах: статичный фон + спрайт. Пиксель-арта в игре нет. Остальная графика — отдельные картинки-ассеты (иконки, аватарки), интерфейс рисует движок. Подробно → `art/style-guide.md`, `art/blender-scenes.md`, `art/characters-in-scenes.md`.
- Звуки, эмбиент и музыка — бесплатные ассеты или по лицензии с указанием автора → `art/audio.md`.

## Ресурсы разработки

- Разработка вместе с Claude, 8–12 часов в день.

## MVP (первая глава, 1–3 часа)

| В MVP | Потом |
| --- | --- |
| Рабочий стол ПК: терминал, почта, магазин | Биржа акций |
| 3–5 вымышленных хакерских программ | Дерево софта, апгрейды железа |
| Смартфон: сообщения + 1–2 уличных взлома | Полный набор приложений |
| Карта из 4–6 локаций, время суток | Новые районы |
| Сытость, энергия, сон, деньги | Здоровье, настроение |
| Заметность + ивенты обыска и ограбления | Больше ивентов и фракций |
| 3–4 персонажа, сюжетная линия + 2–3 сайда | Новые главы и персонажи |
| Сохранения | Онлайна не будет |

## Модель выпуска (набросок)

Первые главы бесплатно или «плати сколько хочешь» на itch.io → свежие главы раньше для подписчиков (Patreon/Boosty) → полная версия платно в Steam, бесплатная глава становится демо. Решать не срочно.
