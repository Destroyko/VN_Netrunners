# История мира

События, на которые можно опираться по ходу сюжета. Новые записи — по порядку времени.
Колонка «Правда» — что на самом деле стояло за событием (то, что игрок может раскрыть).

Годы проставлены от стартовой даты игры: **2 апреля 2026** (`docs/gameplay/time.md`).
Герою 24, значит он родился в 2001–2002.

Рамка для мировых событий: всё, что игрок «пропустил», должно укладываться в **2018–2026** —
это и есть окно комы, которое закрывает архив новостей на его ПК. События до 2018 герой знает
сам, и на них нельзя строить удивление.
