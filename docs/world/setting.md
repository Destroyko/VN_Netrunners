# Сеттинг

## Основа

- **Время:** наше время.
- **Мир:** альтернативная вселенная, очень правдоподобная. Реальных мест и реальных событий нет — всё вымышлено, но похоже на наш мир.
- **Прошлое мира:** в истории были пандемии, утечки вирусов, войны (конкретика → `timeline.md`).
- **Тайна:** мировые корпорации ведут тайные заговоры (образ — Арасака из Cyberpunk). Главному герою по сюжету, возможно, придётся распутывать их супер-тайны.
