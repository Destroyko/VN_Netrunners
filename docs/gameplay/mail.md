# Почта

Почта — приложение и на ПК, и в телефоне (одно и то же, данные одни). Письма приходят эффектом
`send_message` (квест, триггер, консоль F1), формат писем и ответов — `tech/quest-format.md`,
«Каналы получения квестов». Правила — `src/systems/mail/mailbox.gd` (`Mailbox`), приложение —
`src/ui/desktop/mail_app.gd` (`MailApp`), оно только показывает и передаёт действия.

## Что видит игрок

- **Папки:** «Входящие» (с числом непрочитанных) и «Отправленные».
- **Список писем:** значок (не прочитано, прочитано, отправлено), отправитель (у отправленных —
  «Кому»), время (сегодня — часы, раньше — дата) и тема. Длинное обрезается многоточием, целиком —
  в подсказке. Пусто — «Писем нет».
- **Письмо:** тема, отправитель и дата, тело с переносом слов и прокруткой (длинное письмо окно не
  раздувает), вложения «Сохранить к себе», кнопки ответа, «Ответить» своим письмом, «Удалить».
- **Узкий экран** (телефон): то список, то письмо с кнопкой «Назад».

## Удаление

Удалять письма можно — ящик не должен зарастать. Нельзя удалить:

| Письмо | Почему |
| --- | --- |
| Связанное с **идущим** квестом | Письмо — часть задания (адреса, вложения, условия) |
| Письмо, на которое **ещё можно ответить** | Ответ — выбор; удалив письмо, его потеряешь |

Кнопка «Удалить» у такого письма неактивна, причина — в подсказке («письмо нужно для задачи …»).
Письмо без связи с квестом или связанное только с завершёнными квестами удаляется. Отправленные
удаляются всегда: копия у игрока ничего не держит.

**Связь письма с квестом** берётся из данных квестов, отдельного поля у письма нет: квест
ссылается на письмо, если отправляет его (`send_message`) или ждёт, что его прочтут (`read_mail`),
а ещё квест связан с письмом, если его начинает ответ на это письмо (`unlock_quest` в `replies`).
Одно письмо может отправлять несколько квестов (например, «спасибо» за подработку): тогда оно
держится, пока идёт любой из них.

| Что | Где |
| --- | --- |
| `linked_quests`, `delete_block`, `can_delete`, `delete`, `delete_sent` | `Mailbox` |
| Сигнал об удалении | `EventBus.mail_deleted(uid, mail_id)` |
| Номер доставленного письма | `uid` = id, номер из растущего счётчика `next_uid` и день: `mail_rent_reminder#7@d12` (ISS-012); удалённое письмо номер не освобождает |
| Тесты | `test/unit/test_mailbox.gd`, `test/integration/test_desktop.gd` |
| Пробное длинное письмо для вёрстки | `data/mail/mail_test_long.json` (консоль F1) |
