# Устройства

## Домашний ПК — полный рабочий стол

| Приложение | Назначение | В MVP |
| --- | --- | --- |
| Терминал | Взломы, хакерские программы | да |
| Почта | Квесты, заказы, сюжетные письма | да |
| Интернет-магазин | Еда, энергетики, железо, софт | да |
| Подработки / мини-игры | Легальный заработок | да |
| Поиск работы | Отправка резюме, ответы приходят на почту | да |
| Мессенджер | Личные переписки с персонажами, личные квесты | да |
| Сайт группы | Хакерские задания, radiant-квесты, ранг и репутация в группе (открывается после вступления) | да |
| Банк | Баланс, платежи и сроки оплаты (→ `economy.md`) | да |
| Новости | Курсы валют и акций, региональные новости, реакция мира на действия игрока (→ `news.md`) | да |
| Календарь | Дата, день недели, отметки сроков: аренда, платежи, дедлайны квестов. Содержимое собирается из уже существующих данных (→ `time.md`) | да |
| Биржа акций | Дополнительный заработок | нет |
