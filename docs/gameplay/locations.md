# Локации и сцены

Сцена — это фон и объекты под клик. Каждая локация — один файл `data/locations/loc_*.json`;
окно сцены одно на все локации и строится из данных. Новая комната — новый JSON, кода не нужно.

## Формат

```json
{
  "id": "loc_room_desk",
  "title": "Комната",
  "background": {"color": "#1f2433", "image": "res://assets/backgrounds/bg_room_pc_{time}_pc_{pc}.png"},
  "objects": [
    {"id": "monitor", "title": "Монитор", "kind": "monitor", "rect": [0.04, 0.17, 0.45, 0.58]},
    {"id": "back", "title": "Отойти от ПК", "kind": "back", "rect": [0.0, 0.93, 1.0, 0.07], "to": "loc_room"}
  ]
}
```

- `rect` — `[x, y, ширина, высота]` в долях экрана (0..1): сцена тянется под любое окно.
- `mask` — необязательно: PNG с силуэтом предмета (`assets/masks/`, делает `tools/blockout/room_masks.py`
  камерой фона, 1280×720). С маской объект кликается и подсвечивается только по форме предмета, на
  весь экран, а подпись показывается всплывающей подсказкой у курсора (`MaskButton`). `rect` остаётся
  для расположения панели действий и для объектов без маски (там плашка с подписью).
- Локация — это **кадр**, а не комната: у комнаты может быть несколько кадров (стол, кровать,
  дверь), между ними поворачиваются стрелками `turn` или идут полосой `back` внизу экрана («назад»: из комнаты — в коридор, от ПК — в комнату). Кадры — камеры блокаута
  (`tools/blockout/apartment.py`), имя камеры = имя фона.
- `background.image` и `objects[].image` необязательны: пока файла нет, фон — цвет, объект —
  полупрозрачная плашка с подписью. Появилась картинка — встаёт сама (арт, шаг 10 M3).
  `{time}` в пути — `morning`, `day`, `evening` или `night` по часам, `{pc}` — `on` или `off` по состоянию
  компьютера (`bg_room_pc_evening_pc_on.png`, `art/style-guide.md`).
- `requires` у объекта — условия видимости (общий язык `Conditions`).
- У двери: `to` — куда ведёт; `open_requires` — условия, без них дверь заперта;
  `locked_text` — что сказать, если заперта (по умолчанию «Заперто.»).

## Что делает объект (`kind`)

| kind | Клик |
| --- | --- |
| `monitor` | Сразу за ПК, если он включён; иначе «экран чёрный» |
| `system_block` | Панель: питание, «Осмотреть железо», «Вставить» / «Вынуть»; слева инвентарь — флешку можно бросить на системный блок |
| `bed` | Телефон с будильником: «Спать» / «Подождать» (`devices.md`, `time.md`) |
| `container` | Окно инвентаря и рядом контейнер `container` (`fridge`, `room_storage`) (`inventory.md`) |
| `door` | Переход в локацию `to` (плашка на месте двери) |
| `turn` | То же, но поворот к другому кадру комнаты: стрелка ‹ › у края экрана |
| `back` | То же, но «назад»: горизонтальная полоса внизу экрана с подписью из `title` («В коридор», «Отойти от ПК») |
| `look` | Текст `text` в строке внизу |
| `dialogue` | Диалог `dialogue` (`tech/dialogue-format.md`) |

Повторный клик по объекту с панелью, клик по фону или Esc закрывают панель; следующий Esc —
меню игры.

## Правила

- Где герой — переменная `location.current` (в сейве). Нет её или локацию убрали из данных —
  герой дома (`balance.json`, `locations.home` — кадр с кроватью: там начинается игра).
- Фон по времени суток: ночь, утро, день, вечер, ночь, границы те же, что у часов (`balance.json`,
  `clock.time_of_day_bounds`); меняется сам, когда часы перешли границу. Времени, для которого
  картинки нет, подставляется другое (`locations.background_alias`: утро пока рисуется как день).
- Переход внутри квартиры времени не тратит. Дорога по городу будет стоить времени и энергии
  (`needs.md`) — это карта.
- Вырубился в любой комнате — просыпается дома, на кровати.
- Ушёл от ПК — сцена открывается там, где герой (у стола).
- Консоль F1: `go` — где герой и список локаций, `go loc_x` — перейти без дверей.
- Шина: `location_entered(id)`. Цель квеста `{"type": "visit_location", "location": "loc_x"}`
  закрывается на входе; эффект `{"move_to": "loc_x"}` переводит героя (например, после диалога).

## Персонажи в локациях: расписание

Персонаж стоит в локации по **расписанию**: запись «время суток → локация → поза → наряд»
(время суток — из `time.md`). Игра по текущему времени выбирает вариант кадра локации с
персонажем; если записи нет, показывается кадр без него. Клик по персонажу начинает диалог.
Изменения расписания идут данными: запись с условием на общем языке (`quest-format.md`)
добавляет вариант, остальные не трогаются. Подробности и картинки —
`art/characters-in-scenes.md`.

Формат записи в данных пока не утверждён (`open-questions.md`).
