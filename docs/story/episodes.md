# Эпизоды / обновления

Каждый эпизод — законченный кусок с крючком в конце. Новые механики и персонажи вводятся постепенно.

| Эпизод | Сюжет: от → до | Крючок в конце | Новые механики | Новые персонажи | Длина |
| --- | --- | --- | --- | --- | --- |
| 1 (MVP) | Пробуждение → … | | Все базовые системы | 3–4 | 1–3 ч |
| 2 | | | | | |

## Правила

- Эпизод заканчивается на крючке, а не посреди квеста.
- Каждый эпизод даёт хотя бы одну новую механику или новый тип задач.
