# NV-netrunners — дизайн-документация

Рабочее название проекта: **NV-netrunners** (финальное название не выбрано).
Сюжетная одиночная игра: симулятор жизни хакера + визуальная новелла. Онлайна нет.

Правила для ИИ при работе с кодом и документами — в [`CLAUDE.md`](CLAUDE.md).

## Правила, чтобы не было каши

1. **Один факт — одно место.** Если что-то описано в `world/`, в сюжете на это ссылаемся, а не переписываем.
2. **Новая идея сначала в `ideas/inbox.md`.** Переносим в нужный файл, когда она принята.
3. **Принятое решение — строчка в `docs/decisions.md`** с датой и причиной.
4. **Статус в начале каждого файла:** `черновик` / `обсуждается` / `утверждено`.
5. **Ссылки между файлами** — относительные: `[Мать ГГ](../characters/mother.md)`.
6. Имена файлов — латиницей, в нижнем регистре, через дефис.
